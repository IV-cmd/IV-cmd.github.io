About

I'm a Software & DevOps Engineer at CERN, the European Organization for Nuclear Research, based in Geneva, Switzerland. I work on the ATLAS experiment's data-taking infrastructure: Kubernetes platforms, CI/CD, observability, and automation for data-intensive systems. Previously, I was a research software engineer at the Indian Institute of Science (IISc), Bangalore, where I built a self-healing framework for OpenShift cluster logging.

I work on the layers between applications and hardware: Kubernetes, Linux, infrastructure-as-code, observability, and database reliability. I prefer small, inspectable systems and honest measurements over broad claims.

Current interests: site reliability engineering (SLOs, error budgets, incident response), platform engineering (Kubernetes, GitOps, IaC), and distributed systems & storage in C++ — replication, erasure coding, and Linux I/O paths.

Interests: Software Development, Systems Engineering, DevOps, Site Reliability Engineering, Kubernetes, Observability, Distributed Systems, Storage Systems, Cloud Platforms, Open Source.
